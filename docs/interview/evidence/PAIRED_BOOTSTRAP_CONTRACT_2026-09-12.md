# 配对 Bootstrap 评测契约验证（2026-09-12）

## 目的

验证三基线比较不会只报告均值，并防止失败运行被选择性丢弃后虚高结果。本记录只证明统计实现契约，不是模型质量实验。

## 实现口径

- 比较单位是相同 `case_id` 的系统差值，而不是两组互不相关的总体均值。
- 同一 case/system 有多次运行时，只有全部重复无执行错误且该指标均存在，才计算题内均值。
- 任一系统不完整或双方重复次数不一致时，该 case 从该指标的配对比较中排除；执行错误仍由独立 `error_rate` 报告。
- 使用固定 seed 的非参数 bootstrap 输出均值差与 95% CI。
- 指标声明 higher/lower 方向，避免延迟、Token 等成本指标把正负号解释反。
- 有效配对少于 20 时固定输出 `insufficient_pairs`，不能形成方向性结论。
- `--formal` 至少要求 2,000 次重采样。

## 验证

`evaluation.test_metrics` 新增 3 个确定性测试：

1. 25 个配对题验证固定 seed、CI 和 lower-is-better 方向；
2. 验证重复先聚合、含错误重复的整题排除和小样本门禁；
3. 验证任一侧缺失的指标不会进入比较结果。

全套测试结果：109 tests，全部通过。数据集审计与 `git diff --check` 同轮通过。

## 声明边界

Bootstrap 只描述当前评测样本上的抽样不确定性，不能消除黄金标签错误、同源模型裁判偏差、数据泄漏或样本代表性不足。50 条人工批准数据和三系统正式运行尚未完成，因此当前没有可写入简历的 Agentic RAG 提升结论。
