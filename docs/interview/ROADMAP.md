# 简历合格化路线图

## 当前判断

当前项目可以演示，但还不能宣称 Agent 效果优于普通 RAG，也尚未完成学习型简历项目的最低验收。52/52 题已人工审核；已有分层评测显示 Agent 明显弱于 naive RAG，且不同模型结果不能合并。后续以流程清楚、可稳定演示、结果诚实、能解释取舍为目标，不再把研究级效果胜出或生产化能力当成学习型项目的必要条件。

2026-09-21 的逐项复核见 `evidence/RESUME_READINESS_AUDIT_2026-09-21.md`：技术展示条件已基本具备，正式质量门禁失败；当前剩余的简历前置条件是个人仓库/提交归属和本人最低口述验收。

## 学习型项目范围护栏

- 核心必做：RAG 数据链、LangGraph 状态与循环、多源路由、引用/拒答、三基线评测、关键故障复盘。
- 轻量加分：checkpoint、SSE、Trace、预算/熔断、Prompt Injection、重复实验；做到可解释和可验证即可。
- 只讲设计、不在本项目实现：分布式任务平台、外部 Trace、跨进程配额、Kubernetes、企业权限体系，以及与第二个采购助手重复的 MCP/多智能体业务流。
- 新增技术前必须能回答“它补哪个面试知识点、最小证据是什么”；否则只记入扩展讨论，不进入代码。
